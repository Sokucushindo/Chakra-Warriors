Chakra Warriors v{v}
===================

Start ChakraWarriorsLauncher.exe: it checks for updates, downloads them automatically and starts the game with Play.
(You can also double-click ChakraWarriors.exe directly; then you update by hand.)
(If Windows shows "unknown publisher": "More info" > "Run anyway".)
The game starts in English; you can switch to Turkish in Settings > Language.
UPDATE: the launcher does it for you (or put the new ChakraWarriors.exe over the old one). Saves are kept in a separate folder
(%APPDATA%\Godot\app_userdata\Shinobi Yolu) and are not deleted.
If the window does not fit your screen: Settings > Display (fullscreen / window size).

KEYS
W A S D        move
Space / Ctrl   jump / long leap
Shift          dash
Left / Right   attack / block
1-6            jutsu slots
G              hand-seal mode
Q              kawarimi (substitution)
C              charge chakra
R / T          throw / switch tool
E / middle     lock on target
F              interact / talk
H / Y / O      salve / pill / switch pill
V Z X B        eyes / sage / beast / gates
N              draw weapon
J / U          summon command / summon special
L              switch map marker (mission, friend, wanted, target)
Tab I K M      ninja menu / inventory / jutsu / map
Esc            pause

--------------------------------------------------------------------------------
TÜRKÇE
ChakraWarriorsLauncher.exe'yi aç: güncellemeleri denetler, kendisi indirip kurar, Oyna ile oyunu başlatır.
(ChakraWarriors.exe'ye doğrudan da çift tıklayabilirsin; o zaman güncellemeyi elle yaparsın.)
(Windows "bilinmeyen yayıncı" uyarısı verirse: "Ek bilgi" > "Yine de çalıştır".)
Oyun İngilizce açılır; Ayarlar > Dil'den Türkçeye geçebilirsin.
GÜNCELLEME: launcher kendisi yapar (ya da yeni ChakraWarriors.exe'yi eskisinin üstüne koy). Kayıtların bilgisayarında ayrı bir
klasörde durur (%APPDATA%\Godot\app_userdata\Shinobi Yolu), silinmez; kaldığın yerden devam edersin.
Ekran sığmıyorsa: Ayarlar > Ekran (tam ekran / pencere boyutları).
